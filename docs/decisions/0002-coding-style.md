# ADR-0002: Coding Style

## Status
Accepted

## Decision

VyuhaOne adopts established language-specific style guides rather than a custom project style.

- C++: Google C++ Style Guide
- Python: PEP 8

Where project-specific deviations are required, they will be documented explicitly.

## Rationale

Following widely adopted conventions improves readability, onboarding, tooling compatibility, and consistency across contributors.
